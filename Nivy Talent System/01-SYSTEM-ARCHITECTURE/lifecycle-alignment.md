# Lifecycle Alignment Note

**Migrated:** 2026-09-27

## Canonical lifecycle (repo)

```
Source → Application → Profile/CV → Eligibility → 15–20 min Screen
→ Paid Practical Test → Score
→ 3 Small Paid Tasks / Consistency
→ Targeted Training (if needed)
→ Paid Internship/Apprenticeship
→ 30/60/90 Day Probation
→ Core Staff / Talent Pool / Project Work / Exit
```

## Mapping to live Drive operations

| Repo stage | Drive / ops equivalent |
|------------|------------------------|
| Source | Job posts, institutes, social, referrals |
| Application | Contact Information form |
| Eligibility | Academic rules + quiz on form |
| Screen | Role papers (HR Pre Interview, Sales Screening) |
| Practical test | Pre-hiring assignments (HR/BDE) |
| Score | 80% job / 65% internship gates |
| Training | 3-month VA/BDE/HR tracks + MCQ |
| Internship | 65–79% band stipend path |
| Probation | 6 months post training (Orientation) |
| Ranking | Weekly/monthly BDE & HR tier system |
| Exit | 30-day notice; exit interview (HR dept policy) |

## Segments

Long-term Core | Developing Talent | Project Specialist | Part-time/Remote | Trainee | Task Worker

## Scoring principle (architecture)

Task Quality 25, Deadline 20, Instruction Following 15, Communication 10, Problem Solving 10, Learning 10, AI/Tool Usage 5, Documentation 5.  
AI may assist; **employment decisions stay human**.
