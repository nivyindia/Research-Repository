# Verified Vacancies — Outline (Phase F2)

## Fields per vacancy
- Role title
- Employer (Nivy / partner / client)
- Skills required
- Location / remote
- Openings count
- Compensation range (if shareable)
- Verification status (confirmed / tentative)
- Owner
- Expiry / filled date
- Notes

## Rule
- Only list verified or clearly labelled tentative — never inflate
