# Student Portfolio Guide (Draft)

## Folder structure
1. Profile summary (half page)  
2. Skills checklist (assessed)  
3. Project samples (2–4 PDFs/screenshots; no secrets)  
4. Tools list  
5. Assessment summary  
6. Resume PDF  
7. Interview feedback log  

## Rules
- Only your work from this program  
- No client passwords, personal data of third parties, or live credentials  
- Name files: `Project_Topic_YourName_v1`
