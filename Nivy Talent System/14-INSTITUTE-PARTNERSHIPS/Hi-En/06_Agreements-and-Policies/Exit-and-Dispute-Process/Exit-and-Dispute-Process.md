# निकास और विवाद प्रक्रिया (पूर्ण मसौदा)
# Exit and Dispute Process (Full Draft)

## पायलट अंत पर निकास / Exit at pilot end

1. संयुक्त समीक्षा बैठक / Joint review meeting  
2. सहमत दिनों में लिखित निर्णय / Written decision within agreed days  
3. हस्तांतरण: उपस्थिति, अंक, सामग्री, बकाया / Handover: attendance, scores, materials, dues  
4. विद्यार्थी संचार संयुक्त रूप से ईमानदार / Student communication jointly honest  

## विवाद / Disputes

समन्वयक चर्चा (7 दिन) → अधिकृत हस्ताक्षरकर्ता → मध्यस्थता यदि सहमत → कानूनी मंच समझौते के अनुसार।  
Coordinator discussion (7 days) → authorized signatories → mediation if agreed → legal forum per agreement.
