# Hi-En — हिंदी + English bilingual pack

Hi-En — Hindi + English bilingual pack

## नियम / Rule

प्रत्येक महत्वपूर्ण पंक्ति पहले **हिंदी (देवनागरी)** में, ठीक नीचे उसका **English** अनुवाद।

Each key line first in **Hindi (Devanagari)**, immediately below its **English** translation.

## संरचना / Structure

यह फ़ोल्डर `14-INSTITUTE-PARTNERSHIPS` की वही hierarchy रखता है (00–11)।

This folder mirrors the same hierarchy as `14-INSTITUTE-PARTNERSHIPS` (00–11).

मूल (एकल-भाषा) ड्राफ्ट ऊपर के फ़ोल्डरों में रह सकते हैं; **द्विभाषी स्रोत सत्य** यहाँ `Hi-En` में है।

Monolingual drafts may remain in parent folders; **bilingual source of truth** is here under `Hi-En`.

## आगे / Later

अन्य भाषा पैक अलग फ़ोल्डरों में जोड़े जाएँगे (उदा. `Hi-Only`, `En-Only`, आदि)।
