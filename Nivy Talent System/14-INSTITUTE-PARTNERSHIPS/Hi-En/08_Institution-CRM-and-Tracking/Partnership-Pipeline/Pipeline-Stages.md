# Partnership Pipeline Stages

1. नया लीड / New lead  
2. संपर्क हुआ / Contacted  
3. बैठक पूर्ण / Meeting done  
4. प्रस्ताव भेजा / Proposal sent  
5. बातचीत / Negotiation  
6. पायलट सहमति / Pilot agreed  
7. पायलट सक्रिय / Pilot active  
8. छठा माह समीक्षा / Month-6 review  
9. सशुल्क/विस्तार **या** बंद / Paid/expanded **or** Closed
