# WhatsApp Templates — Outline (Phase B2)

## Message types to draft later

| # | Type | Points to include |
|---|------|-------------------|
| 1 | First message | Name, company, context of contact, offer one-page summary, soft ask |
| 2 | Send PDF / one-pager | What file is, 1-line value, ask for 15 min slot |
| 3 | Follow-up (no reply) | Polite nudge, no pressure, option to say busy |
| 4 | Meeting propose | 2–3 time options, place/online |
| 5 | Meeting confirm | Time, place, agenda in 1 line |
| 6 | Meeting reminder | Day-before short reminder |
| 7 | Post-meeting thanks | Thanks + 1–2 notes + “proposal in 2–3 days” |
| 8 | Proposal sent | Link/file + ask questions |
| 9 | Soft decline reply | Respect decision; door open |
| 10 | Pilot start welcome | Next steps list (short) |

## Style rules
- Short paragraphs
- Respectful Hindi
- No spam / no ALL CAPS / no fake urgency
