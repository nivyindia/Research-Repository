# Professional Full-Draft Implementation Plan

**Program:** Institute Growth & Industry Partnership Program  
**Owner:** Nivy Talent System / 14-INSTITUTE-PARTNERSHIPS  
**Created:** 2026-10-14  
**Status:** Active — replaces previous short-stub drafts

---

## 1. Objective

Replace every short / outline-style / mixed-language stub with **professional, complete, ready-to-use full drafts**.

A full draft must be:

- Long enough to be used in real meetings, emails, proposals and training (not 10-line stubs)
- Clear structure, professional tone
- Usable by sales / ops team without further rewriting
- Honest on what is fixed vs TBD (no invented fees, student numbers or placement guarantees)
- Consistent with Master-Plan positioning: *Your Infrastructure. Our Industry Expertise. Shared Growth.*

Language rule for root drafts:
- Primary language: **Professional English** (clean, formal, suitable for institute owners and partners)
- Parallel language packs (Hi-En, Hi-Only, En-Only) will be updated after English full drafts are approved

---

## 2. Quality Standard (Definition of Done for every file)

| Criterion | Required |
|-----------|----------|
| Length | Sufficient for real use (typically 800–3000+ words depending on document type) |
| Structure | Clear headings, numbered sections, tables where useful |
| Tone | Professional, respectful, confident, honest |
| Claims | No invented commercial numbers; mark TBD clearly |
| Placement language | Never guarantee jobs; only verified opportunities |
| Legal | Agreements marked “Draft – subject to legal review” |
| Consistency | Same positioning, same three-party model, same pilot logic across all files |
| Usability | Can be handed to a salesperson or institute coordinator as-is |
