# मास्टर प्लान — संस्थान वृद्धि और उद्योग साझेदारी कार्यक्रम

**स्थिति:** नियंत्रण रूपरेखा पूर्ण

## 1. दृष्टि
मौजूदा कंप्यूटर संस्थानों / कोचिंग केंद्रों को उद्योग-जुड़े प्रशिक्षण और करियर केंद्र बनाना।
नई बड़ी अवसंरचना पर पैसा न लगाकर उनके मौजूदा संसाधनों का उपयोग करना।

## 2. पोज़िशनिंग
**मुख्य नाम:** संस्थान वृद्धि और उद्योग साझेदारी कार्यक्रम  
**पंक्ति:** आपका अवसंरचना। हमारी उद्योग विशेषज्ञता। साथ में वृद्धि।  
**जोखिम कम करने वाला प्रस्ताव:** छह महीने का सीमित पायलट → माप → फिर सशुल्क निर्णय।

## 3. तीन पक्ष
| पक्ष | योगदान |
|------|----------|
| संस्थान | कमरे, कंप्यूटर, स्थानीय विद्यार्थी, समन्वय |
| निवी | पाठ्यक्रम, प्रशिक्षक, अभ्यास, मूल्यांकन, करियर सहायता, सत्यापित अवसर |
| विद्यार्थी | कौशल, पोर्टफोलियो, तैयारी, उपलब्ध अवसरों तक पहुँच |

## 4. वर्टिकल (चरणबद्ध)
1. लेखांकन / कर / वित्त संचालन (प्राथमिकता)  
2. डिजिटल मार्केटिंग और ग्रोथ (प्राथमिकता)  
3. आईटी / सॉफ्टवेयर / एआई (बाद में)  
4. करियर तैयारी (सभी के साथ)

## 5. विद्यार्थी पथ
मूल्यांकन → प्रशिक्षण → अभ्यास → जाँच → पोर्टफोलियो → साक्षात्कार तैयारी → अवसर मिलान → प्रतिक्रिया → फॉलो-अप

## 6. व्यावसायिक रेखाएँ
- **पायलट:** केवल लिखित दायरे में निःशुल्क  
- **सशुल्क पाठ्यक्रम:** राजस्व हिस्सा या डिलीवरी शुल्क (लागत पत्र के बाद)  
- **आउटसोर्सिंग:** अलग अनुबंध

## 7. सफलता
दोहराने योग्य, मापने योग्य, व्यावसायिक रूप से टिकाऊ प्रणाली — स्थानीय अवसंरचना + केंद्रीय गुणवत्ता और नियोक्ता संपर्क।

## 8. खुले निर्णय
- ब्रांड: निवी ग्लोबल बनाम निवी अकादमी  
- पायलट निःशुल्क दायरे की संख्याएँ  
- पहले 1–2 कार्यक्रम + वास्तविक प्रशिक्षक  
- वास्तविक रिक्ति / परियोजना सूची
