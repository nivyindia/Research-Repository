# Objection Handling — Outline

## Common objections → Response direction

| Objection | Direction |
|-----------|-----------|
| “Pehle se placement wale aate rehte hain” | Hum sirf placement nahi — training + practical + assessment + career system ek saath. |
| “Free mein kyun de rahe ho? Baad mein pakadoge?” | Pilot limited scope, likha hua; paid model chhupa nahi — pehle se clear. |
| “Naukri guarantee do” | Guarantee nahi; skills + available opportunities. Confirmed vacancy par hi selection. |
| “Hamare courses kaafi hain” | Courses replace nahi — practical layer + career layer add. |
| “Trainer quality?” | Named process: curriculum, senior review, assessments, monthly report. |
| “Humein investment nahi karna” | Major new infra nahi; existing rooms/PCs. Operational costs pehle se list. |
| “Students fee nahi denge” | Pilot free scope se demand test; paid tab jab value dikhe. |
| “Data / students le jaoge” | Consent + privacy policy; institute relationship respect. |
| “Baad mein outsourcing mein loss?” | Alag commercial schedule; salary, supervision, margin pehle se written. |

## Tone rules

- Never attack their current training.  
- Never hide commercial future.  
- Always invite joint review after pilot.
