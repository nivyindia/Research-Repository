# Success Metrics
Targets, baseline, data source, frequency and owner must be agreed before launch.
| Metric | Definition/evidence | Caution |
|---|---|---|
| Enrolment | Approved aggregate roster | Use minimum data |
| Attendance | Sessions attended / sessions offered | Show denominator |
| Completion | Students meeting predefined criteria | Criteria set first |
| Competency gain | Baseline vs final rubric | Same rubric; sample size |
| Assignment quality | Moderated rubric scores | Anonymise examples |
| Satisfaction | Survey score and response rate | Report non-response |
| Portfolio readiness | Checklist pass | No fake client attribution |
| Interview invitations | Verified invitation | Not a job |
| Employment/paid work | Consented verified evidence | Separate from interviews; avoid causal claims |
Monthly report includes trend, costs, risks, incidents, actions and owner.
