# Institute Growth & Industry Partnership

## उद्देश्य
कंप्यूटर इंस्टीट्यूट/कॉलेज के मौजूदा infrastructure और student reach को Nivy की सत्यापित industry knowledge, practical learning, career readiness और उपलब्ध अवसरों से जोड़ने के लिए यह project workspace है।

## मुख्य सिद्धांत
- पहले institute की जरूरत समझें; फिर tailored proposal दें।
- छह महीने का pilot केवल आपसी लिखित सहमति, स्पष्ट scope और उपलब्ध संसाधनों के आधार पर शुरू करें।
- नौकरी, आय, internship, client project, placement या certification की guarantee न दें जब तक वास्तविक, सत्यापित और लिखित व्यवस्था न हो।
- productive client work, payment, IP ownership और student consent पहले स्पष्ट हों।
- व्यक्तिगत student/contact data public GitHub में न रखें। यहां केवल templates, anonymised summaries और process docs रखें।
- पहले से मौजूद Talent System sourcing/screening workflows को reuse करें; duplicate system न बनाएं।

| 08_Institution-CRM-and-Tracking | Institute pipeline templates; real contact data in approved private system only |
| 09_Career-and-Opportunities | Verified opportunities, candidate assessment, interview prep, client projects |
| 10_Operations-and-Reporting | Pilot tracking, monthly reports, decisions, lessons |
| 11_Archive-and-Previous-Versions | Superseded drafts and change history |

## Suggested order
00 overview → capability verification in 01 → presentation/proposal in 02 → communication in 03/04 → commercial and pilot decisions in 05 → legal review in 06 → training readiness in 07 → CRM and verified opportunities in 08/09 → reporting in 10.

## Status meanings
- **Draft:** working copy; not approved for external use.
- **Needs verification:** factual claim, capacity, price, proof or opportunity must be checked.
- **Approved for use:** named reviewer and approval date recorded.
- **Archived:** superseded, retained for traceability.
