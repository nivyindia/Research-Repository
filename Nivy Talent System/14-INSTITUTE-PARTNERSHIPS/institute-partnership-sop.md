# Institute Partnership System

**Created:** 2026-09-27  
**Goal:** Steady fresher pipeline from colleges / training institutes into Nivy screening → Academy / FT tracks.

---

## 1. Partnership types

| Type | What we get | What institute gets |
|------|-------------|---------------------|
| **Placement MoU** | Campus drives, CV batches, notice-board posts | Structured process, feedback on selects |
| **Training partner** | Pre-screened interns into Academy | Stipend path + completion certificates |
| **Guest / workshop** | Brand + applications | Session on careers / DM / HR skills |
| **Referral faculty** | Named referrals | Recognition; optional success fee policy (if approved) |

---

## 2. Target institute profile

- Degree / diploma colleges with B.Tech, MBA, BBA, MCA, commerce (match Orientation eligibility)
- Lucknow + UP priority; expand to cities in `15-CITY-SOURCING`
- Placement cell contactable; allows remote/job postings

**Avoid:** Mass irrelevant lists with no eligibility filter (wastes HR time).

---

## 3. Onboarding an institute

1. **Scout** — website / AICTE lists / existing employee alma mater  
2. **Intro email** — one-pager: roles (BDE/HR/VA), bands, remote mode, 3-month Academy option  
3. **Call placement officer** — agree channel (WhatsApp group / email batch)  
4. **MoU light** — 1–2 page: data use (CVs for hiring only), no fee from students, feedback timeline  
5. **Pilot batch** — 20–50 CVs or one campus webinar → measure show-up rate to form  
6. **Review** — quarterly: applications, pass rate, joins  

Template seed: use comms library tone; attach role one-pagers from role packs.

---

## 4. Operating cadence

| Cadence | Action |
|---------|--------|
| Weekly | Collect new CV/form links from active partners |
| Monthly | Share openings + Academy batch dates |
| Quarterly | Select-rate report to placement cell (aggregate, no PII abuse) |
| Season | Align with campus placement calendars (final year) |

---

## 5. Data handoff

- Prefer **candidates fill Nivy Contact form** (source = institute_name)  
- If CV bulk: HR logs `source=institute`, `form_payload_ref` when form completed  
- Never publish student PII on GitHub or public channels
