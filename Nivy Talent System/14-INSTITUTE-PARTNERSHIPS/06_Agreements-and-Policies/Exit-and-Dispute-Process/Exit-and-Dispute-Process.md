# Exit and Dispute Process (Full Draft)

## Exit at pilot end
1. Joint review meeting  
2. Written decision (expand / modify / stop) within agreed days  
3. Handover: attendance, scores, materials return rules, pending dues  
4. Student communication agreed jointly (honest, no blame war)  

## Early exit
- Material breach → written notice + cure period (TBD legal)  
- Mutual written termination anytime  

## Disputes
1. Coordinators discuss within 7 days  
2. Founders / authorized signatories escalate  
3. Mediation if agreed  
4. Legal forum per agreement  

## Records
Keep issue log entry for each formal dispute.
