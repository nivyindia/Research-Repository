## 1. Operating Model

Nivy has two primary revenue delivery brands:

- Nivy Next — Digital Marketing, Virtual Assistant, SEO, Social Media, Content, PPC/Ads, Web Development, App Development, AI Automation, IT/SaaS.
- Nivy Advisory — Accounting, Bookkeeping, Tax support, CPA support, CEA/finance operations, compliance and related accounting services.

Shared functions support both brands: CEO/Strategy, Sales, Marketing/Growth, Operations, Project Management, HR/Talent, Finance/Administration, Technology/AI Operations, Customer Success, Quality Assurance, Legal/Compliance and Data/Analytics.

Operating principle: Revenue acquisition first → Delivery capability second → Internal hiring third.

Initial delivery can be outsourced/partner-led. Internal hiring increases when recurring workload, quality requirements and unit economics justify it.

| Model | Best use |
|---|---|
| Fixed Salary | Recurring core workload |
| Part-Time Salary | Recurring limited hours |
| Hourly | Variable operational workload |
| Per Task | Highly repeatable micro-work |
| Per Assignment | Defined deliverable |
| Per Project | Fixed-scope project |

| Commission | Sales/revenue generation |
| Base + Commission | Sales roles with stable base + performance |

Selection rule: role economics + workload predictability + accountability + skill scarcity + measurable output determine the model.

## 16. Universal Candidate Requirements

Core computer literacy: browser, email, files/folders, spreadsheets, documents, uploads/downloads, screenshots and basic troubleshooting.

Data accuracy is especially important for accounting, data entry, CRM, forms, lead research and reporting.

Work behaviour:
- follows instructions
- meets deadlines
- communicates blockers
- accepts corrections
- repeats quality consistently
- documents work
- asks useful questions

AI literacy is preferred across modern Nivy roles: general AI assistants, research, summarisation, spreadsheet/data assistance, content generation and automation awareness.

## 17. Universal Hiring Evidence

Application → Basic Eligibility → 15–20 min Structured Screen → Role-Specific Practical Test → 3 Small Paid Tasks / Consistency → Paid Internship / Work Trial where appropriate → 30/60/90 Probation → Verified Talent.

Evidence priority:
1. observed work
2. paid practical task
3. repeated tasks
4. relevant work history/reference
5. structured interview
6. CV claims
