# Nivy Talent System — Research Hub

**Scope:** Research, architecture, SOPs, templates, prompts, tool research and implementation planning for Nivy's talent acquisition/development pipeline.

**Boundary:** For now ALL Talent System work stays in `Research-Repository`. Do not implement it in `Nivy-Next-AIOS`.

**Lifecycle:** Candidate Pool → Application → Screening → Paid Assessment → 3-task Consistency → Targeted Training → Paid Internship/Apprenticeship → 30/60/90 Probation → Core Staff / Talent Pool / Project Work.

**Principle:** Screen → Test → Observe → Train → Probation → Trust → Promote.

**Research rule:** REUSE → ADAPT → INTEGRATE → BUILD ONLY WHAT IS MISSING.

**Data rule:** Never store candidate CVs, phone numbers, personal emails, IDs, payment data or other PII in GitHub. Operational candidate records belong in an ATS/CRM/database.
