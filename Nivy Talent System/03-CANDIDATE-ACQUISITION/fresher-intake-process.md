## End-to-end fresher path (as operated)

```
Apply (Contact form)
  → Eligibility filter (academic + device + quiz)
  → Screening exam (role paper: HR / Sales / VA)
  → Pre-hiring assignment (role pack)
  → Screening call / interview
  → 3-month training (stipend / incentive)
  → Score gates → Full-time job OR Internship OR exit
  → Probation (6 months post training)
```

## 1. Application intake

**Channel:** Google Form — Contact Information (Fresher Screening Forms)

**Collect:**

- Identity & contact (name, email, phone, WhatsApp, country, gender)  
- Role preference (VA, BDE/Sales, SMM fresher, HR, etc.)  
- CV / portfolio upload  
- Institute referral (if any)  
- Career goal, degree, 10th / 12th / graduation %  
- Program understanding quiz (training bond, incentives, pass thresholds)  
- Ops & WFH mindset quiz (shifts, Workfolio, reports, misconceptions)

**Outputs:** Response row + status labels (Eligible / Selected / Not Eligible, Shortlist, Training, Offer, Performance).

## 2. Eligibility baseline (from Orientation)

### Shared academic rules

| Rule | Value |
|------|--------|
| Degree | Any graduate; preferred B.Tech/B.E/M.Tech/MBA/PGDM/MCA/M.Sc; Bio/Arts not eligible for BDE track as stated |
| Marks | Min 60% or 6 CGPA in 10th, 12th, and highest degree |
| Backlogs | Max 1 active; must clear before joining |
| Education gaps | Max 24 months; declare with documents |
| Course type | Full-time only (no part-time / correspondence) |
| Equipment | Laptop/Desktop + stable internet (mandatory) |

### Role salary bands (orientation snapshot)

| Role | Full-time band | Internship band (65–79%) |
|------|----------------|---------------------------|
| BDE / Sales | ₹18,000–₹30,000 / month | ₹9,000–₹15,000 stipend |
| HR Executive | ₹15,000–₹20,000 / month | ₹7,000–₹10,000 stipend |

### Training gate

- **3 months training** with incentive (e.g. ₹500–2000 per client where applicable)  
- **≥80%** task/report + interview → full-time job  
- **65–79%** → internship with stipend  
- Leave mid-training or fail → not eligible to reapply for **6 months**  
- Bond note on form: exit before completion → ₹5000 payable (as stated on form)

**Work mode:** Remote  
**Meetings:** Regular mandatory meetings for attendance

## 4. Training operations (orientation extract)

| Topic | Rule |
|-------|------|
| Duration | 3 months |
| Full-time | 9 hrs/day (screen ~7.5 hrs); 1 hr lunch + 2×15 min breaks |
| Part-time | 4.5 hrs/day (screen ~3.75 hrs) |
| Initial learning | First 7 days; days 1–2 liberal logging, next 4 stricter |
| Shift selection | Google Form **Monday before first shift**; week locked |
| Shifts | Morning 10–7 / Afternoon 1–10 / Evening 4–3am |
| Daily reports | 3 timed updates per shift (see Orientation for exact slots) |
| Tracking | Workfolio (screen time, activity); miss 2 days without notice → defaulter list |
| Meetings | Tue / Thu / Sat; camera on; from laptop/PC in room (not mobile outdoors) |
| PIP | Fail exam → Performance Improvement Plan; fail PIP → terminate |
| Leave | Advance notice; medical needs certificate else LWP |
| Mentors | Available 12 PM – 7 PM (WhatsApp / call / Meet) |
| Probation after job | 6 months; performance-based continuation |
| Notice | 30 days; leave without notice → repay one month salary |
