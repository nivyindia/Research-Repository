# Role Success Profile — Template

Copy this template for every new role.

## 1. Role identity

- Role ID
- Role title
- Brand
- Department
- Level
- Staffing mode
- Hiring priority

## 2. Role objective

What outcome should this person produce?

## 3. Candidate target

Student / fresher / experienced / specialist; geography if genuinely relevant; work mode; availability; target source types.

## 4. Must-have requirements

Only genuine job requirements.

## 5. Trainable requirements

Skills Nivy can reasonably teach.

## 6. Core competencies

List 5–7 job-relevant competencies.

## 7. Computer and AI requirements

Required computer skills, tools, AI tools and automation level.

## 8. Reliability behaviours

Define 3–5 observable behaviours.

## 9. Discovery source plan

Direct; institution; community; referral; professional; historical; partner.

## 10. Structured screen

Common questions + 5–10 role-specific questions.

## 11. Practical test

Task, expected output, time, payment, rubric and reviewer.

## 12. Three-task consistency plan

Task 1, Task 2, Task 3.

Measure quality, deadline, instruction following, communication, correction response and consistency.

## 13. Advancement gates

Define minimum evidence for training, internship, project pool, core employment, specialist contractor and verified Talent Pool.

## 14. Compensation / engagement

Salary, hourly, per task, assignment, project, retainer, commission, incentive, contractor/partner.

## 15. KPIs

Define 3–7 measurable outputs.

## 16. Evidence and outcome

Evidence required, reviewer, next action and downstream outcome.

## 17. Role-specific risks

Failure patterns that matter for this role.

## 18. Existing reusable assets

Link screening, assessment, training, SOP and role-pack resources.
