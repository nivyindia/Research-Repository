# Common Candidate Discovery Process

The same basic process is used for every Nivy role. Only the role-specific evidence layer changes.

## 1. Define role

Create Role Success Profile before sourcing.

## 2. Define target candidate

Select whether the role needs students, freshers, experienced candidates, specialists, freelancers/contractors, re-engagement candidates or partners.

## 3. Select sources

Create a source mix and campaign ID.

## 4. Discover

Capture legitimate candidate leads with source, campaign, role, discovery date and provenance.

## 5. Basic eligibility

Check only genuine job requirements:
- availability
- work arrangement
- device/internet
- required language
- required qualification/licence where applicable
- genuine prerequisite skills

Avoid weak proxies such as college prestige, demographic characteristics or CV polish.

## 6. Structured screen

15–20 minutes.

Common areas:
- role understanding
- examples of work
- skill level
- tools
- availability
- compensation expectations
- learning behaviour
- deadline handling
- mistake handling
- communication

## 7. Practical evidence

Use a short, clearly scoped, job-relevant paid task where appropriate.

It should be objectively reviewable and not disguised unpaid production.

## 8. Repeated observation

Use three small paid tasks or equivalent controlled observations.

Measure:
- quality
- deadline
- instruction following
- communication
- correction response
- consistency
- supervision required

## 9. Development

If a candidate has potential but a trainable gap, provide targeted training and re-test.

## 10. Work trial / internship / probation

Use real work with clear scope and compensation. Track outcomes.

## 11. Disposition

Route to core, verified talent pool, project pool, contractor, internship, training, re-engagement or not currently suitable.

## 12. Learning loop

Connect final outcome back to source, campaign, role, evidence, assessment and reviewer.

Decision logic:

Discover → Eligible? → Role fit? → Evidence needed → Test → Repeat → Develop if trainable → Observe → Route

AI can research, summarise and flag missing evidence. Human reviewers retain control over consequential decisions.
