# Role Variation Matrix

The discovery engine stays common. What changes is the evidence required to prove capability.

| Role family | Candidate discovery focus | Practical evidence | Reliability evidence |
|---|---|---|---|
| Computer/Data Operator | students, freshers, admin/data communities | data entry, form filling, spreadsheet accuracy | repeated accuracy + deadlines |
| Digital Marketing/VA | marketing students, freshers, VA communities | research + spreadsheet + content/social task | instructions + repeat quality |
| SEO | SEO learners, portfolios, agencies | keyword/on-page/audit task | quality + correction response |
| Social/Content | creators, marketing students, portfolios | content/calendar/caption task | consistency + revisions |
| Paid Ads | performance marketers, specialists | campaign analysis/build task | tracking and budget accuracy |
| Web Development | developer communities, portfolios, colleges | coding/bug/build task | testing + delivery |
| App Development | developer communities, portfolios | feature/bug task | testing + delivery |
| AI/Automation | AI builders, developers | n8n/API/agent workflow | debugging + documentation |
| Accounting/Bookkeeping | commerce students, accountants, institutes | transactions/reconciliation | accuracy + repeat close |
| CPA/CEA Support | qualified finance networks | workpaper/reconciliation | review quality + confidentiality |
| BDE/Sales | graduates, sales communities, referrals | role-play + prospect research | follow-up + activity consistency |
| Project/Operations | generalist operators, graduates | task planning + execution | deadlines + coordination |

## Always common

- Candidate identity
- Source attribution
- Duplicate detection
- Basic eligibility
- Structured screen
- Evidence record
- Reviewer workflow
- Three-task consistency concept
- Outcome tracking
- Talent Pool identity

## Role-specific changes

- target sources
- must-have skills
- screen questions
- practical task
- evidence rubric
- tools tested
- competency weighting
- trainable gaps
- compensation model
- reviewer expertise

## Rule

Start from the common process. Create a separate hiring process only when the role genuinely requires a different evidence model.
