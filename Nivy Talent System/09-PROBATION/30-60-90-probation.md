# 30 / 60 / 90 Day Probation System

**Source:** Orientation (6-month probation), Ranking System, HR Department Policies, architecture scoring  
**Created:** 2026-09-27  
**Applies to:** FT hires post-training/offer (BDE, HR, VA and other roles)

---

## Purpose

Convert offer → confirmed employee using evidence: task quality, reliability, ethics, and role KPIs — not gut feel alone.

## Timeline overview

| Gate | Day | Focus | Decision options |
|------|-----|--------|------------------|
| D0 | Start | Onboarding complete (tools, policies, goals) | — |
| **30** | Month 1 | Fit, basics, reporting discipline | Continue / Early PIP / Exit |
| **60** | Month 2 | Output quality + independence | Continue / PIP / Exit |
| **90** | Month 3 | Sustained performance + ethics | Confirm track / Extend probation / Exit |
| **180** | Month 6 | Formal confirmation (Orientation standard) | Confirmed / Exit |

*Orientation states 6-month probation; 30/60/90 are formal review checkpoints inside that window.*

---

## Scoring at each gate (align with architecture)

| Criterion | Weight |
|-----------|--------|
| Task / output quality | 25 |
| Deadline adherence | 20 |
| Instruction following | 15 |
| Communication | 10 |
| Problem solving | 10 |
| Learning velocity | 10 |
| Tool / AI usage (appropriate) | 5 |
| Documentation / reports | 5 |
| **Total** | **100** |

**Plus role KPIs:** BDE → leads, conversion, revenue, social reach, target %; HR → time-to-hire support, process accuracy, confidentiality (pass/fail critical).

**Ethics overlay:** Ranking system work-ethics dimensions (punctuality, accountability, initiative, communication quality, screen-time efficiency).

### Band guidance

| Score | Meaning | Typical action |
|-------|---------|----------------|
| ≥80 | Strong | On track to confirm |
| 65–79 | Developing | Continue + coaching; mirror internship band logic |
| <65 | At risk | PIP within 7 days or exit process |
| Ethics breach (confidentiality, fraud, harassment) | Critical | Escalate per progressive discipline; may skip PIP |

## Day 0–7 checklist

- [ ] Offer accepted; docs verified  
- [ ] Tools: Gmail/work IDs, Workfolio/Bitrix, CRM access as role needs  
- [ ] Policy ack: HR Policies, Work Guidelines  
- [ ] 30/60/90 goals written with manager (SMART + KPI numbers)  
- [ ] Mentor / TL assigned  
- [ ] First-week shadow or scripted tasks  

## Day 30 review

**Inputs:** attendance, report completeness, first KPI snapshot, mentor note, any flags (Yellow→).  
**Meeting:** 30 min candidate + manager; written summary filed.  
**Outcomes:** Continue | PIP (2–4 weeks) | Exit.

## Day 60 review

**Inputs:** quality samples (3 work products), deadline log, CRM/activity accuracy, peer/mentor feedback.  
**Focus:** less hand-holding, more owned outcomes.  
**Outcomes:** Continue | PIP | Exit.

## Day 90 review

**Inputs:** full scorecard + ethics notes + ranking tier if active.  
**Outcomes:**  
- Recommend **confirm at month 6** path  
- **Extend** focused improvement (documented)  
- **Exit** with notice per policy  

## Day 180 (confirmation)

Formal letter: confirmed / not confirmed. Update ranking eligibility for full incentive tiers.

---

## PIP rules (inside probation)

1. Written gaps + expected metrics + support (mentor hours)  
2. Review every week  
3. Fail PIP → exit process (HR + manager)  
4. Pass PIP → return to normal 30/60/90 track  

Default flag system (HR dept policies) may run in parallel for task backlog.
