## Who enters

| Path | Entry condition |
|------|-----------------|

| **Direct FT** | **≥80%** tasks + interview — use FT offer, not this SOP |

| Track | Stipend band (policy) | FT conversion target |

| BDE | ₹9,000–15,000 / mo | ≥80% end performance → FT ₹18–30k band |

---

## Program length

**Default: 3 months** structured training (Day 1–90), then:

- Convert to FT offer, or  
- Extend internship (written), or  
- Exit / talent-pool hold, or  
- Reapply cooldown if left/failed (Orientation: e.g. 6 months)

---

## Phases

### Phase A — Orientation (Day 0–2)

Mandatory orientation meet; policy + tools; WA group only after attendance; Gmail/tools setup (see VA Basic / HR Training outlines).

### Phase B — Core curriculum (Day 1–30)

Follow role schedule:

- **BDE:** tools → SMM goals → profiles → Bitrix/ChatGPT → networking → funnel → pricing/CRM scripts → objections  
- **HR:** tools → job posting → Bitrix → reports → offers/docs → policies  
- **VA:** SMM goals, KPIs, profiles, scheduling, reachout, reporting  

Daily/weekly reports + Basic MCQ.

### Phase C — Advanced + live practice (Day 31–60)

Advanced MCQ topics; real tasks under mentor; quality checks; ranking “Rising Star” treatment (protect + mentor priority).

### Phase D — Performance test (Day 61–90)

- Day 7 primary interview (schedule) may sit early; **Day 90** performance test + final interview  
- Scorecard same weights as probation architecture  
- Gate: ≥80% → FT offer process; 65–79% → extend or pool; <65% → exit / cooldown

## Operating rules

| Rule | Detail |
|------|--------|
| Shifts | Weekly lock form; FT-like discipline preferred |
| Tracking | Workfolio / approved tool; screen-time expectations scaled for PT if any |
| Reports | 3 daily reports standard where role requires |
| Meetings | Tue/Thu/Sat camera-on when scheduled |
| Leave | Certificate or LWP per Work Guidelines |
| Misconduct | Progressive discipline; academy exit possible |
