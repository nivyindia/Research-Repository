# 3-Task Consistency Protocol

**Source:** System architecture lifecycle (“3 Small Paid Tasks / Consistency”) + assessment scoring weights  
**Created:** 2026-09-27  
**Stage:** After paid practical test / trial task; before or parallel to full training allocation  

---

## Purpose

One good trial can be luck. **Three short paid tasks** test consistency: quality, deadlines, instruction-following, communication.

## When to use

1. Candidate passed screen + one practical (VA trial / BDE or HR pre-hiring assignment)  
2. Borderline 65–79% band — decide Academy vs reject  
3. Role change or returnee after cooldown  

## Design rules

| Rule | Spec |
|------|------|
| Count | **Exactly 3** tasks (or 3 rounds) |
| Size | Each completable in **2–8 hours** |
| Pay | Small fixed fee per task (policy amount TBD by finance); non-zero to filter serious candidates |
| Spacing | 48–72h between deadlines preferred |
| Independence | Tasks must not require prior task files unless testing continuity |
| Blind spots | Rotate skill: e.g. research / writing / data / outreach / process |

## Scoring (per task → average)

Use architecture weights (normalize to 100):

| Criterion | Weight |
|-----------|--------|
| Task quality | 25 |
| Deadline | 20 |
| Instruction following | 15 |
| Communication | 10 |
| Problem solving | 10 |
| Learning (feedback applied on task 2–3) | 10 |
| Tool use | 5 |
| Documentation | 5 |

**Consistency bonus/penalty:** variance across 3 scores — high variance → cap band at “Developing” even if average is high.

## Decision matrix

| Avg score | Consistency | Action |
|-----------|-------------|--------|
| ≥80 | Stable | FT track / priority training |
| ≥80 | Wild swing | Academy + close mentor |
| 65–79 | Any | Academy / internship path |
| <65 | Any | Reject or long cooldown |
| Any ethics issue | — | Stop protocol; HR review |

## Example task sets

### BDE
1. 10 qualified lead rows + sources in CRM template  
2. One discovery-call script + objection replies (5)  
3. Short competitor price comparison for a sample SMB niche  

### HR
1. Screen 10 mock CVs against a JD checklist  
2. Draft one rejection + one interview-invite message  
3. One-day hiring pipeline plan with deadlines  

### VA / SMM
1. 5-post content calendar for a sample local business  
2. Competitor 3-account audit table  
3. One outreach message pack (email + DM) with CTA
