## Sales department

**Purpose:** Ethical, efficient sales aligned with goals.  
**Scope:** Sales staff, managers, field reps, account managers.

| Area | Rule |
|------|------|
| Ethics | No misrepresentation, bribes, kickbacks; protect confidential data |
| Targets | Monthly/quarterly/annual; CRM + call logs + feedback; PIP if underperform |
| Pricing | Official price list; extra discounts need written approval; log in CRM |
| Leads | Follow up within **24 hours**; status: New → Contacted → Qualified → Negotiation → Closed-Won/Lost |
| CRM | Log all calls, meetings, emails |
| Orders | Official system only; complete docs; no verbal-only without written confirm |
| Travel | Pre-approved; expense claims within **7 days** + receipts |
| Reporting | Weekly/monthly: leads, closed deals, revenue, pipeline, challenges |
| Cross-dept | Marketing (leads), Support (post-sale), Product/Ops (feedback) |
| Compliance | Legal review contracts; competition/anti-bribery/privacy laws; approved templates |
