# SOP: Stage 0 – Job Awareness (Entry Control)

## Objective

- Attract high-volume candidates
- Filter out unserious people **before** they enter the system
- Control flow in batches (max 50 candidates)

---

## Responsible Role

- **Operations Executive** (Executes)
- **Funnel Manager** (Approves batch & monitors)

---

## Input

- Candidate database / leads (from ads, referrals, job portals)
- Email list (minimum 50 candidates per batch)

---

## Step-by-Step Actions

### 1. Prepare Batch

- Select **exactly 50 candidates**
- Verify:
  - Email is valid
  - Role relevance (VA / similar)

**Rule:** Do NOT send to more than 50 → keeps control + quality

### 2. Send Job Description Email (Email 1)

Email must include:
- Job role clarity
- Work expectations:
  - 8–9 hours
  - Fixed timing
  - Daily reporting
  - 6-month commitment
- **48-hour strict deadline**
- Application/Test link
- WhatsApp Group link
- WhatsApp Channel link

**Important:**
- Send in **BATCH** (not individually)
- Use **same timestamp** → deadline sync

### 3. Start Deadline Timer

- Note exact time of email sent
- Set Deadline = +48 hours

Track in sheet:
- Email Sent Time
- Deadline Time

### 4. WhatsApp Entry Flow

Candidates will:
- Join WhatsApp Group
- Join WhatsApp Channel

**Your action:** DO NOT engage actively. Only allow passive observation.

### 5. No Follow-up Rule (Critical)

Do **NOT**:
- Remind candidates
- Ping in WhatsApp
- Resend email

This is the first filter (discipline test).

---

## Tracking

| Field            | Example                  |
|------------------|--------------------------|
| Name             | Rahul                    |
| Email            | xyz@gmail.com            |
| Batch            | Batch 1                  |
| Email Sent Time  | 10:00 AM                 |
| Deadline         | 10:00 AM (48h later)     |
| Status           | Applied / Not Applied    |

---

## Success Metrics

- 50 emails sent
- Expected apply rate: 20–30% (good)
- <10% = weak JD / audience issue

---

## Failure Conditions

- Sending >50 candidates → chaos
- Weak JD → low-quality applicants
- Follow-ups → breaks discipline filter

---

## Output

### Applied within 48h
→ Move to **Stage 1 (Application + Test)**

### Not Applied
→ Ignore for current batch  
→ Keep in database for future batch

---

## Strategic Note

This stage is **not** about hiring.  
This stage is about testing seriousness before effort is invested.

> “If they don’t act in 48 hours, they won’t perform in the job.”
