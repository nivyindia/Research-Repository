## Purpose & scope

Smooth daily ops, support all depts, enforce policy, leadership, resource allocation, compliance. Applies to admin staff, executive management, governance/resource roles.

## Policies

| Area | Rules |
|------|--------|
| Facilities | Clean/safe premises; utilities up; maintenance schedules; access control + visitor mgmt |
| Records | Designated filing; role-based access. Retention: financial 7 yrs; HR per law; contracts 3 yrs after end. No unauthorized destruction |
| Communication | Timely, clear, documented decisions; minutes for official meetings; cross-dept coordination |
| Procurement & assets | Office supplies via admin; asset register; annual verification |
| Travel | Senior approval; receipts; preferred vendors |
| Staff support | Tools/stationery; prompt maintenance requests |
| Events | Logistics for meetings/workshops (venue, catering, equipment, invites) |
| Compliance | Staff adherence; report violations; keep policies current |
| Confidentiality | Ops, employee info, strategy confidential; avoid conflicts of interest |
| Leadership | Clear goals; KPI reviews; succession planning |

## Suggested forms

Asset register, visitor log, travel request & expense claim, meeting minutes, maintenance request.
