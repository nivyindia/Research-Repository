## Purpose & scope

Cost-effective, ethical purchasing without disrupting ops. Applies to procurement staff, managers, requesters/approvers.

## Core rules

| Topic | Rule |
|-------|------|
| Vendor selection | Approve before AVL; criteria: price, quality, delivery, ethics. **≥3 quotes** above threshold (e.g. $500) |
| Requisition | PRF with description, qty, date, budget code; dept head approval |
| Purchase order | No buy without approved PO; terms complete; copies to Accounts, requester, vendor |
| Negotiation | Document price changes; prefer bulk savings without quality loss |
| Receiving | Inspect vs PO/DN; report damage/wrong items in **24h**; inventory before issue |
| Payment | Per PO terms; early-pay discounts when useful; no cash above petty limit without Finance |
| Records | Quotes, POs, invoices, DNs ≥ **5 years**; audit-ready |
| Ethics | No gifts/commissions; disclose personal vendor ties; anti-bribery compliance |
| Emergency | Senior approval + justification; report Finance within 24h |
| Supplier review | At least annual; CAPA or replace underperformers |

## Templates in source

PRF, Vendor evaluation sheet, PO, Goods Received Note (GRN), Supplier performance review.
