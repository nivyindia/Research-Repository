## Purpose & scope

Efficient, safe production/logistics/process mgmt to quality and strategy standards. Applies to ops staff, supervisors, managers, contractors in manufacturing, service delivery, supply chain, facilities, planning.

## Policy details

| Area | Rule |
|------|------|
| SOPs | Follow documented SOPs; review ≥ yearly or on process change; train before duty |
| Scheduling | Meet commitments; report delays immediately; schedule changes need written approval |
| Quality | Meet standards before release; checkpoint checks; isolate/rework non-compliant items |
| Equipment | Authorized trained operators only; preventive maintenance; report damage/safety issues; no unauthorized mods |
| HSE | PPE + safety rules; report unsafe conditions; environmental regs; hazardous materials per law |
| Inventory | Accurate system records for RM/WIP/FG; daily stock watch; report discrepancies |
| Vendors | Follow procurement policy; inspect deliveries; report issues within 24h |
| Cost & waste | Efficient use; record scrap; document cost-saving ideas |
| Reporting | Daily production to Ops Manager; document incidents/near-misses; keep audit compliance reports |
| Cross-dept | Sales (priorities), Procurement (materials), Support (delivery status); communicate delays promptly |

## Templates in source

Daily production log, preventive maintenance checklist, inventory control sheet, incident report, order fulfillment tracking.
