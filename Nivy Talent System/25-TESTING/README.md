# Testing

Pilot with 3–5 candidates per role family before mass rollout.

Test intake, duplicate detection, screening, payment/instructions, submission, evaluator consistency, reminders, repeated tasks, training, work-trial QC and 30/60/90 reviews.

Failure modes: duplicate records, missing fields, fake/low-quality profiles, non-completion, missed deadlines without notice, reviewer disagreement, duplicate automation messages, opt-out failure, wrong routing, AI hallucination, unexplained rejection, PII leakage and stale talent-pool availability.
