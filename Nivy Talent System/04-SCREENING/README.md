# Screening

Build a structured 15–20 minute screen for:
- Reliability
- Ownership
- Learning behaviour
- Commitment
- Communication
- Role-specific basics

Example evidence questions:
- What do you do when a deadline cannot be met?
- What do you do when instructions are unclear?
- What did you self-learn recently?
- How do you handle a better-paying opportunity after joining?

Use a scorecard and evidence notes; do not rely on interviewer intuition alone.
