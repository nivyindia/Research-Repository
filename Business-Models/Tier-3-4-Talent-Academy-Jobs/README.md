# Tier-3/4 Talent → Academy → Jobs → Production Model

Purpose: build a distributed talent pipeline from smaller Indian cities/towns by combining training, assessment, real project work, employment and career progression.

Core principle:
Discover talent → train → assess → controlled real work → pay → employ → develop → lead teams.

This is not a “cheap labour” model. The objective is standardized, trained, remotely productive talent with lower operating overhead and strong retention.

Pipeline:
Small-city candidate → introductory learning → assessment → structured training → supervised project → paid internship/probation → Nivy Jobs → specialist → team lead → trainer/partner.

Academy + Jobs flywheel:
Academy creates job-ready talent; Jobs converts talent into income; real work improves training; successful alumni create trust/referrals; advanced courses create an education ladder.

Potential verticals: GST/accounting, data/document processing, digital marketing, SEO/social, VA/operations, web/app/software, AI automation, recruitment operations, customer support and creator/content production.

Creator/modeling programs should have separate safeguarding, consent, contracts, age and image-rights controls.
