# 14-MONITORING-QC-SUSTAINABILITY

This layer converts the CSC/VLE-style network into a controllable, sustainable and scalable operating system.

## Core principle
**Trust is system-generated: transparent transactions + measurable output + auditability + support + fair economics.**

## Partner/centre scorecard
- Revenue and transaction volume
- Active customers
- Repeat customers
- Service quality / error rate
- Customer complaints
- Training/certification status
- Reporting compliance
- Settlement accuracy
- Growth rate
- Compliance incidents
- Centre uptime/availability

## Suggested status bands
- 90–100: Premium / expansion-ready
- 75–89: Healthy
- 60–74: Watch / improvement plan
- Below 60: Remediation / suspension review

Thresholds are proposed Nivy controls, not CSC official thresholds.

## Employee productivity
Measure **role-specific output**, not attendance alone:
Role → KPI → output → QC → customer feedback → incentive → training → promotion/PIP.

## Retention system
Partner:
Customer pipeline + recurring earning + training + technology + territory rights (where contractually appropriate) + higher-margin services + career/upgrade path.

Employee:
Clear role + fair compensation + skill growth + incentives + promotion path + workload visibility + performance recognition.

## Anti-fraud controls
- Unique partner/centre IDs
- Unique transaction IDs
- Digital payment preference
- Role-based access
- No shared passwords
- Maker-checker for sensitive actions
- Immutable/auditable settlement records
- Customer confirmation/feedback
- Refund and dispute SOP
- Periodic audit
- Automatic anomaly flags

## Scalability rule
Do not franchise a process that has not been proven in a controlled pilot. First prove unit economics, SOP, training, QC and partner profitability; then expand.
