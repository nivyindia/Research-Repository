# Hardware & Connectivity Minimum List — L3 Centre Partner

**Folder:** `06-OPERATIONS-AND-TRAINING/`  
**Created:** 2026-10-04  
**Status:** Activation gate template (pilot)  
**Rule:** Specs are **minimum practical** for assisted digital services — not a copy of any official CSC portal RAM/HDD table. Update when provider apps require more.

---

## 1. Required before activation

| Item | Minimum | Notes |
|------|---------|-------|
| Computing device | 1× laptop or desktop | Windows/Android as required by authorised portals |
| Display | Readable screen for forms | Dual monitor optional |
| Printer | Inkjet or laser capable of A4 | Receipts + application prints |
| Scanner | Flatbed or ADF or phone scan workflow that meets portal quality | PDF clarity for KYC uploads |
| Webcam | HD for video KYC / photo where required | |
| Internet | Stable broadband or 4G with failover plan | Test login to all pilot portals |
| Power backup | UPS or inverter covering PC + router for outages | Define local min runtime |
| Seating / counter | Public-facing, safe, accessible | Site checklist |
| Storage | Lockable drawer for documents | No unsecured Aadhaar print stacks |
| Display board | Printed **fee list** + grievance number | Mandatory compliance |

---

## 2. Conditional (service-dependent)

| Item | When required |
|------|----------------|
| Biometric device (STQC / provider-approved) | Aadhaar / AePS / bank BC path |
| PIN pad / micro-ATM class device | Banking cash services under bank rules |
| Extra PC | Training lab / multi-counter |
| CCTV | If policy + lawful disclosure requires |

**Do not** buy biometric/banking hardware until the specific authorised service path is confirmed in writing.

---

## 3. Explicitly out of scope for Nivy kit claims

- Nivy does not ship government CSC kits by default.  
- Partner owns capex unless a separate written kit programme exists.  
- No requirement to display CSC branding hardware.
