# Training & Certification Rubric — L3 Centre Partner (Pilot)

**Folder:** `06-OPERATIONS-AND-TRAINING/`  
**Created:** 2026-10-04  
**Status:** Activation gate rubric  
**Rule:** No LIVE status without pass. Reuse Academy materials where licensed; Nivy brand/ops modules original.

---

## 1. Certification purpose

Confirm partner can run a compliant centre: authorised services only, fee transparency, no CSC impersonation, basic ops, safe data handling.

---

## 2. Modules (pilot minimum)

| Module | Content focus | Method | Pass rule |
|--------|---------------|--------|----------|
| M1 Programme & legal posture | Not CSC; disclaimer; territory basics | Read + quiz | ≥80% quiz |
| M2 Ops daily | Opening/closing checklist; receipts; float | Demo + practical | Checklist walkthrough pass |
| M3 Fees & overcharge | Published list; playbook | Scenario | Correct response to fee challenge |
| M4 Brand & claims | No gov/CSC marks; no income claims | Quiz + visual ID | 100% on brand items |
| M5 Data hygiene | No OTP capture; minimise PII | Scenario | Zero critical fails |
| M6 Service subset | Pilot catalogue SOPs only | Practical on sandbox/demo | Complete 2 happy-path services |
| M7 Support path | Ticket + escalation severity | Drill | Raises sample ticket correctly |

Optional later: banking/AePS only if authorised path exists + separate module.

---

## 3. Scoring

| Result | Meaning |
|--------|--------|
| **PASS** | All modules meet pass rule; eligible for hardware/fee-list gates |
| **CONDITIONAL** | Minor ops gaps; recheck within 7 days; not LIVE |
| **FAIL** | Brand/data/legal posture fail, or critical scenario fail; retrain |

**Automatic FAIL:** Suggests using CSC logo; stores OTP in notes; invents fees; guarantees income to mock citizen.
