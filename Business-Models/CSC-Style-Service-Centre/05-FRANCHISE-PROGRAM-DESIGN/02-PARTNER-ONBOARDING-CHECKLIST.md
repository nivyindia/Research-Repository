# Partner Onboarding Checklist — Centre Partner (L3)

**Folder:** `05-FRANCHISE-PROGRAM-DESIGN/`  
**Created:** 2026-10-04  
**Status:** Operational draft  
**Related:** `01-NIVY-CHANNEL-PROGRAMME-STRUCTURE.md`, `06-OPERATIONS-AND-TRAINING/01-OPERATIONS-FRAMEWORK.md`

---

## Stage A — Lead & application

- [ ] Lead source recorded (web / referral / camp / distributor)
- [ ] Application form complete (identity, address, proposed location, experience)
- [ ] Mobile + email verified
- [ ] Self-declared non-conflict / existing agencies disclosed
- [ ] Territory interest noted (pincode / ward / block)

## Stage B — KYC & due diligence

- [ ] Government photo ID
- [ ] Address proof
- [ ] PAN (for payments / GST as applicable)
- [ ] Cancelled cheque / bank proof
- [ ] Photo of proposed centre location (interior/exterior)
- [ ] Police verification / local reference (if policy requires)
- [ ] Watchlist / fraud check (internal process)
- [ ] Territory overlap check vs existing partners

## Stage C — Commercial & legal

- [ ] Term sheet / fee schedule explained (written)
- [ ] Agreement signed (legal-approved template only)
- [ ] Deposit / fee received and receipted (if any)
- [ ] GST / invoice setup if applicable
- [ ] Partner code issued

## Stage D — Training & certification

- [ ] Access to LMS / training pack
- [ ] Core ops module complete (daily checklist, privacy, payments)
- [ ] Priority service modules (as authorised)
- [ ] Practical assessment passed
- [ ] Certificate / activation flag in CRM

## Stage E — Launch readiness

- [ ] Hardware checklist passed (PC, print/scan, UPS, connectivity, biometric if needed)
- [ ] Branding within guidelines (no CSC/gov logos)
- [ ] Published Nivy fee list displayed
- [ ] Grievance contact displayed
- [ ] Portal logins provisioned (least privilege)
- [ ] Test transactions / dry run
- [ ] Opening announcement plan (local, compliant)

## Stage F — Probation (e.g. 30–90 days)

- [ ] KPI pack agreed (txn quality, complaint rate, training completion)
- [ ] Weekly check-in scheduled
- [ ] First audit / mystery sample
- [ ] Probation pass → full status **or** extend / exit per agreement

## Stage G — Steady state

- [ ] Monthly MIS submission
- [ ] Refresher training calendar
- [ ] Commission statement acknowledged
- [ ] Annual renewal / performance review date set

---

## Exit / replacement triggers (ops flags)

- Fraud, data abuse, overcharging vs published list  
- Loss of required upstream authorisation  
- Prolonged inactivity  
- Brand guideline breach  
- Insolvency / death / transfer (agreement process)  

---

## Records to keep

Application, KYC copies (lawful retention), signed agreement, training certificate, launch checklist, probation report, commission acknowledgements.

**Never store:** customer OTPs, biometrics templates, unnecessary full Aadhaar numbers in onboarding files.
