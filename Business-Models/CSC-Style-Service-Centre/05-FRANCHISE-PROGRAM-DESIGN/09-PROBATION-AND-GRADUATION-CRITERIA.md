# Probation & Graduation Criteria — L3 Centre Partner (Pilot)

**Folder:** `05-FRANCHISE-PROGRAM-DESIGN/`  
**Created:** 2026-10-04  
**Status:** Pilot policy draft  
**Default probation:** 90 days from LIVE

---

## 1. Purpose

Decide whether a pilot centre **continues**, **extends probation**, or **exits** — based on compliance and ops quality, not vanity transaction volume alone.

---

## 2. Day 30 review (early warning)

| Check | Target |
|-------|--------|
| Training certificate still valid | Yes |
| Fee list displayed (photo or visit) | Yes |
| Brand check (no CSC/gov marks) | Pass |
| Critical incidents (fraud/data/brand) | Zero |
| MIS / daily samples submitted | Per pilot cadence |
| Tickets responded with partner cooperation | Acceptable |

**Outcome:** Continue / Coaching plan / Suspend (if critical).

---

## 3. Day 60 review

Same as Day 30, plus:

| Check | Target |
|-------|--------|
| Mystery fee/brand sample (if scheduled) | Pass |
| Open critical incidents | None unresolved |
| Partner engagement (training refresh if CONDITIONAL) | Done |

---

## 4. Day 90 graduation decision

| Result | Criteria (all required for GRADUATE) |
|--------|--------------------------------------|
| **GRADUATE** | No critical incidents; fee + brand passes; training current; cooperation with audits; agreement in good standing |
| **EXTEND** (30–60 days) | Minor ops gaps only; written improvement plan |
| **EXIT** | Critical compliance failure; refusal to remediate; false CSC claims; overcharge pattern; data abuse |

Volume/revenue is **context only** in pilot — not a sole graduation KPI.

## 6. Exit process (summary)

1. Written notice per agreement  
2. De-branding deadline  
3. Final settlement window  
4. Territory register status → REVOKED  
5. CRM status → EXIT
