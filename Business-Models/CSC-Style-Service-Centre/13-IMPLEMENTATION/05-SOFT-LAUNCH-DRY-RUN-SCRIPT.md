# Soft-Launch Dry-Run Script

**Folder:** `13-IMPLEMENTATION/`  
**Created:** 2026-10-04  
**Status:** Rehearsal script before first LIVE pilot centre  
**Goal:** Prove ops + compliance path without public recruitment scale-up

---

## 1. Participants

| Role | Who |
|------|-----|
| HQ ops lead | |
| Sales / partner success | |
| Mock L3 operator | Internal staff or trusted volunteer |
| Mock citizen | Staff with **synthetic** identity only |
| Observer | Notes gaps |

**Never** use real Aadhaar/PAN/OTP of non-consenting persons in dry-run.

---

## 2. Pre-conditions (T-1 day)

- [ ] Pilot service catalogue freeze (subset)  
- [ ] Fee-list template version posted at mock counter  
- [ ] Hardware checklist walkthrough  
- [ ] Daily opening form printed  
- [ ] Ticket channel reachable  
- [ ] Escalation form available  
- [ ] Disclaimer language on any mock marketing material  
- [ ] CRM stage board ready (NEW → … → LIVE)

---

## 3. Scenario sequence (2–3 hours)

### Scene A — Opening
1. Operator runs opening checklist.  
2. Observer verifies fee list + no CSC marks.  
3. Float recorded.

### Scene B — Happy path service
1. Mock citizen requests an **authorised** pilot service.  
2. Operator follows SOP: identity check per portal rules, no OTP capture in notes.  
3. Receipt issued; reference logged (synthetic).

### Scene C — Fee challenge
1. Citizen challenges a fee.  
2. Operator shows published list; if error, follow overcharge playbook (no real refund needed if zero charge).  
3. Log incident form sample.

### Scene D — Portal failure
1. Simulate portal down.  
2. Operator records failed txn; no unofficial workaround.  
3. Ticket raised; L2/HQ first response clock starts.

### Scene E — Brand fail injection
1. Observer places a mock “CSC franchise” sticker.  
2. Operator/HQ must detect and remove; document brand incident.

### Scene F — Closing
1. Closing checklist + reconciliation.  
2. MIS daily fields filled (dictionary).  
3. Debrief.

---

## 4. Pass criteria

| Gate | Pass |
|------|------|
| Checklists usable without confusion | Y/N |
| Fee-list compliance demonstrated | Y/N |
| No PII policy breach in notes | Y/N |
| Ticket path works | Y/N |
| Brand violation handled | Y/N |
| Time-to-complete acceptable for real day | Y/N |

Any **N** → fix SOP before real partner activation.

---

## 5. Outputs after dry-run

- Annotated gaps list  
- Updated SOP snippets if needed  
- Go / no-go for first external L3 activation
