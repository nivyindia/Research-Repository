## 2. UP CSC 3.0 structure (state programme — distinct from national CSC SPV narrative)

From Centre for e-Governance / UP IT sources (verify currency on each use):

| Element | Description |
|---------|-------------|
| Scheme | UP Common Service Center; **CSC 3.0** effective from **16 Nov 2020** (stated 5-year 3+2 frame in CEG material) |
| Model | PPP; prepaid user-charge; self-sustainable |
| Per district | **Two District Service Providers (DSP)** selected via tender, with DeGS involvement |
| DeGS | District e-Governance Society, chaired by District Magistrate |
| Wallets | DSP prepaid wallet on e-District portal; VLE prepaid wallet on DSP portals; portals integrated |
| Mandate example | DSP mandate cited in some decks: at least 2 CSCs per Gram Panchayat and urban coverage rules — **confirm live tender/contract** before relying |

**SDA-style role:** Centre for e-Governance (CEG), Government of UP, appears as key state e-governance node (overview pages on upite.gov.in/ceg).

**Implication for Nivy:** UP already has a formal **district DSP tier**. A parallel commercial channel must not claim DSP status. Partnership options (if any) require formal commercial contracts, not “CSC franchise” branding.

### Example revenue-share model (Panchayat Sahayak / Sachivalaya context — not universal VLE rate)

One published UP Panchayati Raj / Sachivalaya note described **₹30 user charge** per e-District service split approximately as:

| Share | Amount |
|-------|--------|
| Panchayat Sahayak | ₹5 |
| Gram Panchayat | ₹10 |
| District e-Governance Society | ₹10 |
| Service owner | ₹3 |
| Centre for e-Governance | ₹2 |

**Status:** Specific to that programme context. **Do not treat as the default commission for every UP CSC VLE.** Mark VERIFY for general VLE e-District share.

## 5. Nivy expansion notes for UP

1. **Density:** >1 lakh centres → differentiation via support quality, niche services, training, and honest branding.
2. **Dual system:** National CSC SPV network **and** UP CSC 3.0 DSP/e-District stack — map carefully which services sit where.
3. **Pilot districts:** Prefer districts with documented DSP names + strong e-District volume; avoid claiming government partnership.
4. **Legal:** Any G2C facilitation only through lawful agent/portal access.
