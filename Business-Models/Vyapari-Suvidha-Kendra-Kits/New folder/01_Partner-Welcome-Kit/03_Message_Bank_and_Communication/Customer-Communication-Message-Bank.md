# Customer Communication Message Bank / ग्राहक संचार संदेश संग्रह

**स्थिति:** प्रारूप / **Status:** Skeleton — message categories only

## Message categories / संदेश श्रेणियाँ
1. Enquiry acknowledgement / पूछताछ की प्राप्ति
2. Missing-document request / लंबित दस्तावेज़ का अनुरोध
3. Case status update / केस स्थिति अपडेट
4. Expected next step without unapproved time promise / बिना अप्रमाणित समय-वादे के अगला कदम
5. Service completion and handover / सेवा पूरी होने और handover की सूचना
6. Reminder with contact preference / संपर्क preference के अनुसार reminder
7. Complaint acknowledgement and escalation / शिकायत प्राप्ति और escalation
8. Opt-out confirmation / संदेश बंद करने की पुष्टि

## Approval fields / अनुमोदन फ़ील्ड
Message ID, channel, Hindi copy, English copy, reviewer, approval status, version, effective date. / Message ID, channel, Hindi copy, English copy, reviewer, approval status, version, effective date.

## लंबित inputs / Pending inputs
Official contacts, approved response targets और channel-specific consent rules की पुष्टि बाकी है। / Official contacts, approved response targets, and channel-specific consent rules require confirmation.
