# 02 — CRM and Prospecting Tools

## Required assets
- Customer Lead Register
- Lead Status Definitions
- Follow-up Tracker
- Customer/Business Prospect Profile
- Daily Sales Report
- Order Tracker
- Customer Acquisition SOP
- Duplicate lead and ownership rules

## Minimum fields
Lead ID, date, source, business name, contact consent/status, service interest, owner, status, next action/date, quote/order reference and outcome. Do not place unnecessary personal data or KYC files in GitHub.
