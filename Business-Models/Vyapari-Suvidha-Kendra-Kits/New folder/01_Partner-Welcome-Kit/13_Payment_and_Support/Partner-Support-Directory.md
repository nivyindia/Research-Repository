# Partner Support Directory / Partner support directory

**स्थिति:** प्रारूप / **Status:** Skeleton — verified contacts required

## Directory fields / Directory फ़ील्ड
- Issue category and urgency / Issue category और urgency
- Official support channel / आधिकारिक support channel
- Responsible team/owner / जिम्मेदार team/owner
- Operating hours and response target only if approved / Operating hours और response target केवल approved होने पर
- Escalation level and alternate contact / Escalation level और alternate contact
- Last verified date and source/approver / Last verified date और source/approver
