# Approval and Version Control

| Content | Owner/reviewer | Approval gate |
|---|---|---|
| Company profile/credentials | Company/brand owner | Claims and contacts verified |
| Services/scope | Operations/service owner | Active availability and inclusions confirmed |
| Prices/fees/commissions | Authorized commercial owner | Rates, costs, shares and effective date approved |
| Distributor incentives | Authorized commercial owner | Written plan approved |
| Leads/marketing support | Marketing/operations owner | Scope, eligibility and exclusions documented |
| Agreements/privacy/compliance | Authorized legal/compliance reviewer | Terms reviewed |
| Scripts/creatives | Sales/brand owner | Claims and assets approved |
| Print booklets | Project owner plus relevant approvers | All P0 facts approved and version assigned |

Each final artifact should show owner, version, status, last updated date, approver, source links and next review date.

Statuses: Draft · Source Required · Needs Approval · Approved · Superseded · Archived.

Change process: update canonical source → record reason/effective date → identify dependent files → update both short/long versions → obtain approval → archive superseded versions.
