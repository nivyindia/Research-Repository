# Complete File Outline Register / सभी फ़ाइलों की विस्तृत रूपरेखा

## 1. Current scope / वर्तमान कार्य-सीमा

**हिंदी:** अभी इस register का उद्देश्य सभी documents की file-by-file outline तय करना है, full content लिखना नहीं। जहाँ कोई file पहले से मौजूद है, उसे `Existing` चिह्नित करें; जहाँ केवल folder/README या प्रस्तावित asset है, उसे `Outline only` या `Proposed` कहें। File name या folder name को इस बात का प्रमाण न मानें कि उसका पूरा content मौजूद या verified है।

**English:** The current purpose of this register is to define a file-by-file outline for every document, not to write full content. Mark a file that already exists as `Existing`; where only a folder/README or a proposed asset exists, mark it `Outline only` or `Proposed`. Do not treat a filename or folder name as proof that its full content exists or is verified.

**हिंदी:** `Catalogue 1.52.docx` फिलहाल latest catalogue reference है। अभी किसी भी price, commission, fee, margin या earnings figure को compare, calculate, recommend या publish नहीं करना है। Commercial sections की outline बनाई जा सकती है, लेकिन सभी values pending रहेंगी।

**English:** `Catalogue 1.52.docx` is the current latest catalogue reference. Do not compare, calculate, recommend, or publish any price, commission, fee, margin, or earnings figure at this stage. Commercial sections may be outlined, but all values must remain pending.

## 2. Mandatory bilingual standard / अनिवार्य द्विभाषी मानक

हर outline और बाद में तैयार होने वाली हर file में पहले देवनागरी हिंदी और उसके तुरंत बाद English translation होगा। यह नियम headings, descriptions, tables, checklists, scripts, FAQs और instructions पर लागू होगा। Filenames, repository paths, standard product names और technical identifiers English में रह सकते हैं।

Every outline and every subsequently completed file must present Hindi in Devanagari first, followed immediately by its English translation. This applies to headings, descriptions, tables, checklists, scripts, FAQs, and instructions. Filenames, repository paths, standard product names, and technical identifiers may remain in English.

## 9. Outline completion criteria / Outline पूरा होने की शर्तें

An outline is complete when its file path and existence status are recorded; its audience and purpose are clear; the heading/section sequence and intended tables/forms are listed; dependencies and required evidence are noted; unresolved inputs are marked; and its scope does not duplicate another asset without an explicit cross-reference.

किसी outline को complete तभी मानें जब file path और existence status दर्ज हों; audience और purpose स्पष्ट हों; headings/sections और प्रस्तावित tables/forms सूचीबद्ध हों; dependencies और जरूरी evidence दर्ज हों; unresolved inputs marked हों; और किसी दूसरे asset से duplicate scope होने पर स्पष्ट cross-reference हो।
