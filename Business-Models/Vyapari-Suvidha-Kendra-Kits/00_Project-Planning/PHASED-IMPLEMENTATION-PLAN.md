**Current stage:** Outline planning only  
**Priority:** First define exactly which topics belong in every file. Do not start full document drafting until the outline set is reviewed and approved.

---

## 1. Objective

Prepare a complete, file-by-file content outline for:
- `01_Partner-Welcome-Kit/`
- `02_Distributor-Field-Meeting-Kit/`
- `03_Shared-Master-References/`
- `00_Project-Planning/`

Each file outline must identify its purpose, users, headings/topics, required inputs, dependencies/master references, and approval needs.

## 2. Mandatory Working Rules

1. **Outline first:** define topics for every file before writing full content.
2. **Audit before changing:** inspect the files already present in GitHub and map them to the approved structure.
3. **No duplicate content:** one authoritative master reference for shared company, catalogue, brand, contact, and document-control information.
4. **Preserve existing work:** do not delete, overwrite, rename, or move existing files without recording the action and checking links/dependencies.
5. **Commercial hold:** do not add prices, fees, commissions, incentives, settlement rates, earnings calculations, earnings promises, or unapproved commercial claims. Outline headings and required inputs only.
6. **Source-backed content:** do not invent company details, services, legal requirements, contacts, support commitments, or approved claims. Mark unknown items as `TBD / SOURCE REQUIRED`.
7. **Catalogue control:** `Catalogue 1.52.docx` is the latest working catalogue reference. Do not calculate, revise, or publish pricing at this stage.
8. **No unnecessary files:** merge overlapping topics where practical, but keep a separate file when it has a distinct workflow, owner, approval, or tracking purpose.
9. **Spreadsheet rule:** use XLSX only for structured records, repeated updates, filters, statuses, or reporting. Define columns before adding sample records.
10. **Language and consistency:** use clear, practical wording; keep role names, statuses, terms, and master references consistent across both Kits.
