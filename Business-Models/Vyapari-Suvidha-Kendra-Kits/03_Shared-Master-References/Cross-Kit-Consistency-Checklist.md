# Cross-Kit Consistency Checklist / दोनों kits की consistency checklist

**स्थिति:** प्रारूप / **Status:** Skeleton — QA checklist

## Checks / जाँच
- Company/model facts match across both kits / दोनों kits में company/model facts समान हों
- Partner/Retailer and Distributor roles remain distinct / Partner/Retailer और Distributor की भूमिकाएँ अलग रहें
- Service names align with the working catalogue / Service names working catalogue से align हों
- Customer journey and handoff steps align / Customer journey और handoff steps align हों
- All commercial values remain pending / सभी commercial values pending रहें
- Marketing, lead and support commitments have evidence/approval / Marketing, lead और support commitments के लिए evidence/approval हो
- Hindi-first bilingual order is followed / पहले हिंदी फिर English का क्रम हो
- Source links, versions and status labels are consistent / Source links, versions और status labels consistent हों
- Privacy and no-real-customer-data rule is respected / Privacy और no-real-customer-data rule का पालन हो

## Review fields / Review fields
Reviewer, date, issue ID, affected file, correction, resolution and approval status. / Reviewer, date, issue ID, affected file, correction, resolution और approval status.
