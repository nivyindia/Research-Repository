# 03 — Message Bank and Communication

## Required assets
- First-contact WhatsApp and call scripts
- Service-specific customer pitches
- Quote-sharing message
- Document reminder
- Payment reminder and receipt confirmation
- Order acknowledgement and status update
- Delay / missing-document message
- Delivery confirmation and feedback request
- Complaint acknowledgement and escalation
- Referral request and follow-up sequence

All messages must use approved pricing, realistic timelines and authorized claims. Include opt-out/consent practices where relevant.
