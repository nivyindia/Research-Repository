# Archive Index and Version Log / Archive index और version log

**स्थिति:** प्रारूप / **Status:** Skeleton — archive register

## Fields / फ़ील्ड
1. Asset ID and original filename / Asset ID और original filename
2. Version and status / Version और status
3. Superseded date and reason / Superseded date और कारण
4. Replacement file/link / Replacement file/link
5. Retention and access classification / Retention और access classification
6. Owner, reviewer and archive date / Owner, reviewer और archive date

## Rule / नियम
Archive record के बिना पुराने approved assets को delete न करें। / Do not delete superseded approved assets without an archive record.
