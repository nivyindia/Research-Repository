# VA Live Orientation Call – Script & Structure

## Objective

- Set clear expectations
- Filter out unserious candidates
- Align with company work culture

## Structure

### Step 1: Introduction (2–3 mins)
- Welcome, company + work model brief
- Clarify: "This is a performance-driven system, not a casual job"

### Step 2: Work Structure (5 mins)
- 8–9 hours daily, fixed hours, 6 days/week
- Remote but strict tracking
- "If you want flexible/part-time, this is NOT for you"

### Step 3: Daily Targets & Work (5 mins)
- Daily task assignment + reporting mandatory
- KPI-based tracking (daily, weekly, monthly)

### Step 4: Strict Rules (5 mins)
- No work = No pay
- No report = No work counted
- Missing work = warning → removal
- 2 days no activity = immediate removal
- "We don’t chase people. Either you work or you are out"

### Step 5: No-Excuse Culture (5 mins)
- No "network issue", "busy today", "will do later"
- "This system rewards execution, not excuses"

### Step 6: Commitment & Discipline (5 mins)
- 6-month minimum commitment
- $50 penalty if leaving early
- Attendance mandatory
- "If not sure, better leave now"

### Step 7: Reality Check
- "This is not easy"
- "You will be monitored"
- "Only consistent people survive here"

### Step 8: Drop-Off Filter (MOST IMPORTANT)
- Ask: If not comfortable with fixed hours / daily work / strict discipline → leave now
- Pause 30–60 seconds
- Goal: Let weak candidates disqualify themselves

### Step 9: Next Steps
- Inform about next stage / trial if applicable
- "Only those who perform move forward"

### Final Close
- "We are building a serious team. If ready to work, you grow fast. If not, this is not the right place."

**Note for facilitator:** Be strict, not emotional. Don’t convince. Filter, not impress.
