# ChatGPT Context

This folder is the curated memory bridge between ChatGPT work and the GitHub repository.

For each meaningful period/session, capture:

- What was discussed
- What was decided
- What was completed
- What remains
- Files/repositories affected
- Next action

Raw exports stay under `Chats/ChatGPT/`. This folder contains only useful operational summaries so ChatGPT can resume work without rereading everything.
