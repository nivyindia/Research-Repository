# Nivy Company Visual System — Implementation Plan

## Purpose
Create a governed, editable Draw.io visual system that makes the whole company understandable and executable by the owner, departments, employees, contractors and AI agents.

## Scope
1. Company structure and brand architecture
2. Vision, strategy and goals
3. Annual → quarterly → monthly → weekly → daily planning
4. Department and employee goal cascade
5. Projects, milestones, tasks and subtasks
6. Recurring work and operating cadence
7. Sales, marketing and service delivery
8. Talent/hiring pipeline
9. Finance and KPI flows
10. Data, knowledge, AIOS and automation architecture
11. Governance, responsibility, approvals and escalation
12. Review, learning and continuous-improvement loops

## Design principle
One source of truth per concept. Diagrams are visual indexes, not duplicate databases.

Core execution chain:
Company → Department → Role → Goal → Plan → Project → Milestone → Task → Output → KPI → Review

Core information chain:
Source Data → Raw Repository → Organized Knowledge → Approved Canonical Record → Operational System → AI/Human Execution → Result → Evidence

## Acceptance criteria
A diagram is DONE only when it opens successfully in Draw.io, has clear scope, represents the intended entities and relationships, matches canonical terminology, records supporting sources, contains no secrets, passes visual review, and has tracker evidence.

## Future change process
Change request → source verification → diagram update → validation → tracker update → commit → release note
