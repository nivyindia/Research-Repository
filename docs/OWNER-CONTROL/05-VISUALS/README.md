# Visual Control System

All owner-level visual maps are stored here as editable **draw.io** files.

## Core visual set

1. `NIVY-OWNER-CONTROL-MASTER.drawio` — where the owner is, what is active, and what comes next.
2. `NIVY-HISTORY-TIMELINE.drawio` — reconstructed work over previous months.
3. `NIVY-MASTER-ROADMAP.drawio` — major plans and future direction.
4. `NIVY-TASK-HIERARCHY.drawio` — company → workstream → task hierarchy.
5. `NIVY-SALES-ACQUISITION-FLOW.drawio` — lead-to-revenue flow.
6. `NIVY-AUTOMATION-MAP.drawio` — systems, integrations and automation opportunities.

Do not create a new diagram merely because a new topic appears. Add it to an existing map when appropriate.
