# Nivy Owner Control — Start Here

This is the control layer for the owner's work across ChatGPT, GitHub research, company planning and execution.

## Use this area to answer four questions

1. What have I been doing?
2. Where am I now?
3. What do I need to do next?
4. What plans/ideas are waiting for later?

## Structure

- `01-HISTORY/` — reconstructed record of work and major decisions by period.
- `02-CURRENT/` — current position, active work and immediate next actions.
- `03-PLANS/` — plans, roadmaps, future initiatives and deferred ideas.
- `04-TASKS/` — task hierarchy and execution breakdown.
- `05-VISUALS/` — master and supporting draw.io diagrams.
- `06-CHATGPT-CONTEXT/` — curated ChatGPT work summaries, not raw chat storage.

## Rule

ChatGPT may update this control layer after meaningful work. Detailed source material remains in its appropriate repository location.
