# Master Task Map — Owner View

**Last updated:** 2026-10-02

## Company Goal
**International project revenue with a repeatable acquisition and delivery system.**

### A. Acquire Capacity — ACTIVE

- Screen applications
- Interview shortlisted candidates
- Run paid test
- Select resource
- Onboard
- Train on ICPs, channels, scripts, offers and tracking
- Start supervised lead generation
**Dependency:** candidate pool / applications.

#### A2. Marketplace Acquisition Capacity
- Define marketplace role/workflow
- Prepare profiles/services/proposal assets
- Establish bidding and follow-up process
**Dependency:** service packaging and marketplace positioning.

### B. Activate Acquisition — ACTIVE
#### B1. CPA / Tax / Bookkeeping
- Define ICPs
- Finalize service packages
- Prepare outreach/sales materials
- Connect to direct and marketplace channels

#### B2. Digital / Software / AI / VA
- Define ICPs
- Finalize service packages
- Prepare outreach/sales materials
- Connect to direct and marketplace channels

#### B3. Direct Outreach

- Build prospect-list workflow
- Enrich/verify business contact data
- Run outreach
- Follow up
- Qualify responses

#### B4. Partnerships / Referrals
- Define partner ICP
- Identify partner categories
- Prepare partner proposition
- Outreach and follow-up

### C. Convert — ACTIVE

- Client onboarding

### D. Deliver & Retain — ACTIVE
- Project setup

### E. Systemize — ACTIVE-BUILD

## Next-action hierarchy

**Now:** BDE/sales acquisition hiring → selection → activation.

**Then:** activate direct outreach + marketplace acquisition across the packaged CPA/Tax/Bookkeeping and Digital/Software/AI/VA offers.

**Then:** strengthen conversion, delivery and retention.

**Later:** systemize and scale what is already working.

## Status convention

ACTIVE = execution now  
ACTIVE-BUILD = implementation supporting current execution  
STRATEGIC = important but not the immediate execution bottleneck  
WAITING = dependent on an external action  
DEFERRED = intentionally postponed  
DONE = verified complete
