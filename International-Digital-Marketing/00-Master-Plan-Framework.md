- North-star goal

### A01.6 Change (4Cs — Change)

- AI and search shifts

### A01.7 Digital SWOT

## C02. Reuse architecture
- RESEARCH → DISCOVER → REUSE → ADAPT → INTEGRATE → BUILD ONLY MISSING
- Library: Frameworks, SOPs, Tools, Agents, Templates, KPIs, Sources

## C03. AI / Agent readiness
- Skill format: Purpose, Input, Knowledge, Instructions, Tools, Output, Evaluation
- Agent format: Trigger, Input, Memory, Tools, Permissions, Reasoning, Actions, Validation, HITL, Failure, Logging, KPI, Cost
- Multi-agent pipeline concept (Research → Strategy → Channel agents → Analytics → Optimization)

## C04. Internationalization requirements
- Multi-country prioritization
- Language, currency, legal, cultural, platform fit
- Technical: domains, hreflang, local entities
- Operating model: central vs local

## C05. Business-type adaptability
- Modular notes for B2B / B2C / SaaS / Ecommerce / Marketplace / Local services
- Same spine; different channel and offer emphasis

## C06. Digital Marketing OS (end-to-end flow)
```
Business input
→ Research
→ Situation analysis
→ Objectives
→ Strategy
→ Customer / ICP / Offer
→ Channel strategy
→ Content + creative
→ Distribution (Reach)
→ Acquisition (Act/Convert)
→ CRM / Retention (Engage)
→ Data + Measurement
→ Optimization
→ Automation + AI + Agents
→ Scale
```
