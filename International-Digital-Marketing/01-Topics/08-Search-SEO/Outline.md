# Search-SEO — Outline (stronger points)

> Sources: Google Search Central; SEO strategy templates (goals → audit → clusters → roadmap).

## 1. Goals & KPIs
- Business outcome first (leads/sales), then search metrics
- Organic non-brand clicks, rankings for target clusters, conversions
- Local pack / Shopping visibility if relevant
- AI answer / citation presence (track, don’t chase “secret AI SEO”)

## 2. Audit (top issues only)
- Crawl / index / canonical problems
- Core Web Vitals / mobile
- Thin or duplicate content
- Internal linking gaps
- Backlink risk / digital PR opportunities
- Local: GBP, NAP consistency

## 3. Topic & keyword architecture
- Clusters by **intent** (informational / commercial / transactional)
- One primary URL per cluster
- Map clusters to funnel stage and persona
- International: per-locale keyword differences (link Global-Local)

## 4. Classic workstreams
- Technical backlog (prioritized by impact)
- On-page and content brief standards
- Off-page / digital PR targets
- Ecommerce: product feed, category architecture if applicable

## 5. AI search / AEO points to cover later
- Entity clarity (brand, products, authors)
- Source-worthy pages (original data, clear answers)
- Measurement of mentions/citations where tools allow
- Foundation = helpful, indexable, reliable content (Google guidance)

## 6. Process steps
1. Goals + baseline
2. Audit summary (5–10 findings)
3. Cluster map
4. 90-day fix + content roadmap
5. Measurement rhythm (GSC, analytics, conversions)

## 7. Outputs
- Audit one-pager
- Cluster map
- Quarterly roadmap
- Measurement checklist
