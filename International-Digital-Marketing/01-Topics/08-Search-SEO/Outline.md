# Search-SEO — Outline

## 1. Classic SEO pillars
- Technical SEO (crawl, index, speed, mobile)
- On-page (titles, content, internal links)
- Off-page / digital PR / links
- Local SEO (GBP, citations, maps)
- International SEO (link Global-Local)
- Ecommerce / enterprise / programmatic SEO where relevant

## 2. Search surfaces
- Google (web, Discover, Images, News, Shopping, Maps)
- Bing and other engines if material
- YouTube as search
- Featured snippets / sitelinks / structured data

## 3. AI search / AEO / GEO
- AI Overviews / AI answer engines
- Entity and brand mention visibility
- Citation and source strategy
- Tracking AI visibility (what we will measure)
- Note: foundational SEO + helpful content first (no “secret AI SEO”)

## 4. Other search
- Social search (TikTok, IG, Reddit, etc.)
- Voice / visual / marketplace search

## 5. Strategy steps
1. Goals and SEO KPIs
2. Audit (technical + content + links)
3. Keyword / topic clusters by intent
4. Content and fix roadmap
5. Measurement (Search Console, ranks, conversions, AI presence)

## 6. Outputs
- Audit summary (top issues only)
- Topic cluster map
- Quarterly SEO roadmap
