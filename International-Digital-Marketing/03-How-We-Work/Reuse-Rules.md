# Reuse Rules

**Order (hamesha):**

1. Hamare `02-Reusable` mein pehle se hai? → **Use karo**  
2. Official / industry / open-source hai? → **Adapt karo**  
3. Do cheezein mil sakti hain? → **Integrate karo**  
4. Thoda badalna hai? → **Extend karo**  
5. Sach mein missing hai? → **Naya banao**, phir `02-Reusable` mein save karo
