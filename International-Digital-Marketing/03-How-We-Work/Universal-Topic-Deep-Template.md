# Universal Topic Deep Template (37 layers)

Use this under every topic when writing `Details.md`.  
Current `Outline.md` files are Level-1 checklists only. Phase 2 = fill these layers.

```
TOPIC NAME
│
├── 01 Definition
├── 02 Purpose (why in the plan)
├── 03 Business objectives linked
├── 04 Customer / journey objectives
├── 05 Scope and out-of-scope
├── 06 Situation / current state audit
├── 07 Market context and trends
├── 08 Audience / segments for this topic
├── 09 Competitor practices
├── 10 Strategy choices
├── 11 Tactics (exact methods)
├── 12 Process (ordered steps)
├── 13 SOP (reusable procedure)
├── 14 People / roles / RACI
├── 15 Tools / software
├── 16 Resources / inputs
├── 17 Data requirements (events, fields)
├── 18 Automation opportunities
├── 19 AI use cases
├── 20 AI skills (if any)
├── 21 AI agents (if any)
├── 22 Integrations / APIs / MCP
├── 23 KPI set
├── 24 Measurement method and sources
├── 25 QA checklist
├── 26 Budget / ROI model
├── 27 Risks and failure modes
├── 28 Compliance / policy
├── 29 Internationalization notes
├── 30 Business-model variants (B2B/B2C/SaaS/ecom/local)
├── 31 Existing frameworks to reuse
├── 32 Reusable resources (link to 02-Reusable)
├── 33 Benchmarks / case references
├── 34 Templates to produce
├── 35 Known gaps
├── 36 Implementation plan
└── 37 Optimization loop
```
