# Archive

Home › 04_ARCHIVE

## Purpose

Retired and superseded material only. Nothing is deleted from Company OS — it is moved here with history preserved (Doc 03, Doc 04 Lifecycle: Retired).

## Structure

```
04_ARCHIVE/
  PROJECTS/     ← finished project folders from 02_PROJECTS
  DOCUMENTS/    ← retired documents (optional subfolders by department or year)
  SNAPSHOTS/    ← point-in-time package snapshots if needed
```

## Rules

1. Before moving a document: set `Lifecycle Status: Retired` and `Superseded By: [code or N/A]`.
2. Keep original Code and filename; do not renumber.
3. Projects: move the entire project folder from `02_PROJECTS/` into `04_ARCHIVE/PROJECTS/`.
4. Access remains Internal (or higher) unless the Owner reclassifies.
5. Archive is not a second working tree — no active edits here except metadata corrections.
