- Any business type (B2B, B2C, D2C, SaaS, Ecommerce, Local, Professional services, Agency, Startup, SME, Mid-market, Enterprise, Personal brand, Creator, Marketplace, Franchise, Education, Healthcare, Finance, Real estate, Technology, Manufacturing, Hospitality)

## 8D Universal Definition Framework

Every topic / capability / process is defined with these 8 blocks only:

| # | Block | Defines |
|---|-------|--------|
| 1 | **WHY** | Purpose + Objective + Expected Outcome |
| 2 | **WHAT** | Scope + Inputs + Outputs |
| 3 | **HOW** | Process + SOP + Workflow |
| 4 | **WHO** | Owner + Human / AI Agent + Responsibility (RACI) |
| 5 | **WITH WHAT** | Tools + Software + Resources + APIs |
| 6 | **AUTOMATE** | Automation + AI + Agents + Integrations |
| 7 | **MEASURE** | KPI + Quality + Cost + ROI |
| 8 | **IMPROVE** | Feedback + Optimization + Reuse + Scale |

This replaces oversized 20+ field schemas. Extended metadata lives in machine-readable frontmatter / YAML, not in the human definition.
