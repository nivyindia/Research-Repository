# Principles

1. REUSE FIRST — Research → Discover → Reuse → Adapt → Integrate → Extend → Build only what is missing
2. 8D ONLY for human topic definitions — avoid schema bloat
3. SINGLE CANONICAL — one component, many references
4. AGENT DEFAULT = REUSE — build needs gap + approval
5. INTERNATIONAL BY DESIGN — not a US plan with translation
6. MODULAR BY BUSINESS MODEL — adapters, not one plan
7. OFFICIAL SOURCES WIN — platform docs and standards over random blogs
8. PROVENANCE ALWAYS — source, date, license, adaptation notes
9. HITL FOR RISK — claims, legal, budget, data residency, new frameworks
10. COVERAGE DRIVES WORK — matrix and gaps set the backlog
