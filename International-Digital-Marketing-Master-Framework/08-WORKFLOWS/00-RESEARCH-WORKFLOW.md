# Research Workflow

1. Select topic_id
2. Search Component Library
3. Search Research-Repository
4. Search official documentation
5. Search industry frameworks
6. Search open-source / agent libraries
7. Record with provenance
8. Classify: REUSE | ADAPT | INTEGRATE | EXTEND | BUILD
9. Update coverage matrix
10. If BUILD → gap ticket + HITL if framework-level

Never start by writing a new framework.
