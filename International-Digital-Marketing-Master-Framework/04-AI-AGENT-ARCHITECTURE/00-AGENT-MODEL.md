# AI / Agent Architecture

## Agent Decision Graph

```
MASTER TOPIC
     ↓
RESEARCH AGENT  →  search library + official + open-source
     ↓
EXISTING FRAMEWORKS / COMPONENTS
     ↓
REUSE → ADAPT → INTEGRATE
     ↓
8D DEFINITION (stub → complete)
     ↓
SOP / AUTOMATION / AI AGENT
     ↓
KPI / QA → OPTIMIZATION AGENT → SCALE
```

## Core Agent Types

| Agent | Responsibility |
|-------|----------------|
| Research Agent | Discover existing components; never invent first |
| Reuse / Adapt Agent | Map discovered assets into 8D + library refs |
| Builder Agent | Create only gap-approved missing pieces |
| SOP Agent | Turn processes into executable SOPs |
| Automation Agent | Design n8n/Make/Zapier/MCP workflows |
| AI Skill Agent | Package prompts + tools as skills |
| Domain Agents | SEO, Content, Paid, Social, CRM, Analytics, etc. |
| Orchestrator | Multi-agent plans, dependencies, HITL gates |
| QA / Optimization Agent | Measure, gap-check, improve |
| Coverage Agent | Maintain coverage matrix |

## Topic → Agent Pipeline

Topic → Capability → Process → SOP → Skill → Agent → Workflow → Automation → KPI → Feedback → Optimization

## Human-in-the-Loop Gates

- New framework creation  
- Budget-affecting automation  
- Public claims / legal / compliance content  
- Cross-border data processing decisions  
- Agent permission elevation
