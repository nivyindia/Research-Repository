# Metadata Schema (Machine-Readable)

YAML frontmatter or sibling meta.yaml for every defined topic and library component.

Required for agent-readiness: id, status, depends_on, inputs, outputs, tools, agents, kpis, success_criteria.

Optional: geo_tags, business_models, hitl_required, privacy_notes, mcp_servers.

See template fields: version, taxonomy_path, triggers, skills, apis, failure_conditions, related_components, provenance.
