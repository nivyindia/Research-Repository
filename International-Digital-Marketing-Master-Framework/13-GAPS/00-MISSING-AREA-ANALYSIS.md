1. Marketing finance depth — budget allocation, MMM ops, procurement  
2. Partner / affiliate operating system  
3. Offline ↔ online unified measurement  
4. Product-led growth (PLG) depth  
5. Marketplace seller vs owner dynamics  
6. Crisis / reputation incident response  
7. Accessibility ops (WCAG in production SOPs)  
8. Agent evaluation & safety harnesses  
9. MCP server catalog for marketing tools  
10. Multi-brand / multi-BU governance

- AI Search / AEO / GEO  
- Commerce / retail media  
- Creator as first-class  
- Internationalization  
- Privacy / ad-tech governance  
- 8D lightweight schema  
- Reuse-first agent order
