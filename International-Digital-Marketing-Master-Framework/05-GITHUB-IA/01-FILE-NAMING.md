# File Naming Conventions

- Prefer kebab-case
- Prefix with zero-padded numbers for ordered sequences (00-, 01-)
- IDs in content: DM-L1-08-AI-SEARCH
- English for architecture; localized content under localization paths later

## Standard topic files (Phase 2+)

00-README.md, 01-OVERVIEW.md, 02-8D-DEFINITION.md, 03-RESEARCH.md, 04-TOOLS.md, 05-RESOURCES.md, 06-SOP.md, 07-AUTOMATION.md, 08-AI.md, 09-KPI.md, 10-QA.md, 11-GAPS.md, meta.yaml

Create on need; do not force empty files.
