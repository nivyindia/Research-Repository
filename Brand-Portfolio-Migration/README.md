# Brand Portfolio Migration — Research Repository

## Purpose
Organize existing and future business assets across four service brands without losing source material or creating conflicting versions.

## Brands in scope
- **Nivy Next** — Technology, AI, website development, web/app/software development.
- **Nivy Crafts** — Graphic design, video editing, motion graphics and creative production. (Earlier folder was created as `Nivy Crafts`; one reference image uses singular `Nivy Craft`. Keep the existing folder spelling unless the owner explicitly changes it.)
- **Nivy Hype** — Social media, paid advertising, PPC and performance marketing.
- **Nivy Ops** — Virtual assistance, remote support and business operations.

## Working rule
**Inventory → inspect → classify → propose destination → approve → migrate → verify.**

This project is currently in planning/audit preparation. This commit does not move, delete, rename or overwrite existing business files.
