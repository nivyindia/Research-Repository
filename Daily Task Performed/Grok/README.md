# Grok दैनिक कार्य रिपोर्ट्स

## उद्देश्य
हर दिन Grok के साथ किए गए कार्यों की विस्तृत दैनिक रिपोर्ट हिंदी में तैयार करना, मौजूदा रिपोर्ट अपडेट करना और उसी रिपोर्ट की मासिक आर्काइव कॉपी रखना।

## फोल्डर संरचना
```
Daily Task Performed/
└── Grok/
    ├── README.md
    ├── YYYY-MM-DD.md          # दैनिक रिपोर्ट (वैकल्पिक मुख्य कॉपी)
    └── YYYY-MM/
        └── YYYY-MM-DD.md      # मासिक आर्काइव कॉपी
```

## नामकरण नियम
- तारीखें भारतीय समय (IST, UTC+05:30) के अनुसार।
- फाइल नाम: `YYYY-MM-DD.md`
- मासिक फोल्डर: `YYYY-MM`

## रिपोर्ट अपडेट प्रक्रिया
1. उस दिन Grok के साथ हुई बातचीत और उपलब्ध कार्य-इतिहास की समीक्षा।
2. वास्तविक कार्यों, शोध, विश्लेषण, दस्तावेज़, निर्णयों और लंबित कार्यों की पहचान।
3. हिंदी में विस्तृत दैनिक रिपोर्ट तैयार करना।
4. `Daily Task Performed/Grok/YYYY-MM/YYYY-MM-DD.md` में बनाना या अपडेट करना।
5. संबंधित GitHub फाइलों, कमिट्स और सत्यापित संसाधनों के लिंक जोड़ना।
6. केवल Grok से संबंधित वास्तविक कार्यों की रिपोर्ट; ChatGPT के कार्यों को शामिल न करना।
7. उपलब्ध साक्ष्य के बिना किसी कार्य को पूर्ण न बताना।

## समय क्षेत्र
सभी तारीखें और समय भारतीय मानक समय (IST, UTC+05:30) में।
