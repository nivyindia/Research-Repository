## Definition of done

A service is **Training Ready** only when it has:
- verified service identity
- availability/authorization status
- official portal/process source
- documents/eligibility
- step-by-step SOP
- current YouTube training link or documented search fallback
- practical task
- QC checklist
- escalation/refund guidance where applicable
- last verified date
