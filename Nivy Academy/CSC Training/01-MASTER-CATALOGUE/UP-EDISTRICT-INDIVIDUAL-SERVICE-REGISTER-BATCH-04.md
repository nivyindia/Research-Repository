# UP e-District Individual Service Register — Batch 04

## Scope
Official UP district-government material confirms that the e-District project includes certificates, complaints, Public Distribution System (PDS), pension, Khatauni/land-record services, revenue disputes and employment-centre registration. The UP IT & Electronics 2025 presentation records 353 services from 54 departments through Jan Seva/e-District. This batch records service families only where exact live portal rows were not retrievable; no invented portal service IDs are used.

## Master-register rule
One canonical Service ID per actual service. Multiple evidence sources attach to that canonical record. Family-level evidence must not be counted as additional services.

## Required fields before Training Ready
Exact portal display name; service ID where exposed; department/authority; CSC/Jan Seva authorization; login; eligibility; documents; file rules; authentication; official fee; operator charge; SLA; workflow; payment/receipt; application number; status; correction/objection/rejection; approval authority; download/verification; escalation; current YouTube aid; practical test; QC checklist; last verified date.

## Training reference
A current 2026 practical video was found covering UP e-District ID creation/login, Income, Caste, Residence, Birth/Death, status and certificate download. Treat it as secondary training material and verify the current official portal before using it in an SOP.

## Limitation
The live official e-District/e-Sathi operator catalogue was not directly retrievable in this pass. Therefore this is not presented as the complete 353-service list, and fees/SLAs/documents are not frozen from third-party guides.
